### DEPLOY: feat/4516-specialist-knowledge-canon · 20261127-131227Z

Eight specialists now ship with a canon of their craft: Rebecca, Marlowe and Uma in the core team,
Sebastian and Nolan in the developers team, and Rutger, Hugo and Fiona in the life-hub team. Each canon
is a short page beside the manual listing the sources that define the field, each with a one-line key
finding and a grade (A, B or C). The specialist reads it on demand at the start of a task, so it costs
nothing on turns that do not need it. Before searching the web, these specialists now look in three
places, in order:
- their own canon;
- the source store the repo's lens names, if it names one (a life hub's `Bronnen` database, for example);
- the web, citing only sources they opened.

A web find worth keeping comes back with the deliverable as a row for that store. A source that belongs
in the canon itself arrives through an inbound issue.

**Score:** 2

#### What makes this deploy extra special

The first answer of a research, security, UX, performance, behavioural, lifestyle or financial
specialist now starts from the strongest sources of its field instead of a fresh web search, and a
search done once can be reused by the next session.

**Score:** 3

### DEPLOY: feat/4520-asana-intake · 20261127-120841Z

`dkj-repo-workflow-bwj` gains `asana-intake`, the front door for a colleague's Asana task that reaches
development. It reads the task, checks whether it is already filed or resolved (tracker open and closed,
the trunk and the live branch, merged PRs), verifies the cause the ticket states, and settles one
outcome: already resolved, an issue filed through `report-issue`, or no repo change. It ends with a
readiness verdict, and any question for the requester is drafted in the chat, never posted.

**Score:** 3

#### What makes this deploy extra special

A developer in a BWJ store repo no longer retypes the same three-step prompt for every Asana ticket, and
a ticket an earlier PR already resolved is caught before a duplicate issue is filed.

**Score:** 3

### DEPLOY: feat/4513-bronnen-library · 20261127-110250Z

The life-hub specialists now keep external evidence apart from the dossiers, where a hub keeps a
source library. A paper, study, guideline or textbook becomes one row in that library, never a
dossier. What it means for the person goes into the dossier as an update, citing the row through
the relation. Ian places sources by asking whether a thing is about the person or about the world.
Onyx lays no links to or between sources. Rutger delivers each source he opened as a row: the GRADE
strength of that single source sits on the row, and the evidence status of the mechanism stays on the
mechanism page. Rutger, Hugo and Fiona look a source up in the library before searching the web. So
does Rebecca, when she researches for a hub.

**Score:** 2

#### What makes this deploy extra special

A life-hub user finds a source once and every specialist reuses it, instead of each one searching
the web again for evidence another already found.

**Score:** 3

### DEPLOY: feat/4511-rutger-sourced-mechanisms · 20261127-095615Z

Rutger, the life hub's Behavioral Analyst, now grounds the explanation half of a conclusion in the
literature rather than in model memory, and keeps what he finds. He reads the hub's mechanism library
first. That library has one page per mechanism, with its sources, its evidence status and the date it
was last checked. He searches the web only when a page is missing, more than 12 months old or marked
contested, and never with the person's data. After a search he delivers the new page for Ian to
place. Each pattern he reports has the same shape:
- the observation, with its data points;
- the mechanism, with a source he opened and its status (established, mixed or contested);
- at least one competing explanation;
- a confidence level.

**Score:** 2

#### What makes this deploy extra special

A life-hub user can check every explanation Rutger gives against its source, and sees how solid the
underlying research is. Research done once stays in the hub's library instead of being repeated.

**Score:** 3
