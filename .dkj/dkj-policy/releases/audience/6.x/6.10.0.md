# Release notes v6.10.0 🚀

**Date:** 2026-11-07\
**Type:** Minor\
**For whom:** consumers of this product

Admin opens on Today, the day gets a plan, and the workflow's folders move to where they belong

## What changed

Two items ask something of you, so start with those. Run them right after you update the plugins
(`update-plugins` refreshes the marketplace clone too). Until you do, the session-start check names what is
left and prints the line to fix it.

### Action: repoint the extension import in `CLAUDE.md`

This applies to every repo that enables `bwj-development` or `dkj-solutions`. Both extensions now live under
`plugins/dkj-policy/extensions/`, so the `@`-import line in your `CLAUDE.md` points at a folder that no longer
exists. **Nothing errors**, but the extension's rules silently stop loading. Run `adopt-workflow-folder.ps1 -Apply`
from the `adopt-dkj-policy` skill, or `adopt-bwj-development` in a BWJ store repo. It rewrites the line to
`.../plugins/dkj-policy/extensions/<extension>/CLAUDE.md`. Your `.claude/settings.json` needs no change.

### Action: move the workflow folder to `.dkj/dkj-policy/`

The workflow's own folder (the changelog, the release notes, the branch documents) moves from the repo root
to `.dkj/dkj-policy/`. That separates what your repo builds from what an installed plugin keeps in it. Part 1
of `adopt-dkj-policy` with `-Apply` makes the move in one `git mv`, and it repoints `scripts/repo-config.ps1` and
`.gitignore` along the way. Until you run it, the old location keeps working.

### Admin opens on Today

Admin's first page is now **Today**. It shows the day goal with a progress bar and the plan, with each item
ticked off as its PR or issue closes. It also lists what got done outside the plan, what you deliberately
left for another day, and the week so far.

### Plan your day with Paula

The new `day-plan` skill gives your working day a beginning and an end. In the morning Paula proposes one day
goal and the items for it, each with an hour estimate. She holds the day between 6 and 8 hours, so she
refuses a thin day and an overfull one, and she also refuses an addition that does not fit. You can overrule
her by giving a reason, which comes back at the close-out. In the evening the close-out reads GitHub, says
what got done and what moves to tomorrow, and ends with "You can close the day". On Friday the week gets
the same close-out.

### Hub is now Admin, in the code too

Folders, hooks and scripts now say *admin* where the screen already did. All you do is update the plugins.
The first session start copies your day plan and banner state to the new folder, and an old `/hub` bookmark
redirects. If you set `DKJ_HUB_AIRSQUATS_GIST`, rename it to `DKJ_ADMIN_AIRSQUATS_GIST`. This release
still reads the old name, and the next one will not.

### Smaller things

- `tidy-machine` now removes the dead install records a moved or deleted checkout leaves behind, instead of
  handing you the uninstall lines to paste. `-DryRun` still only shows them.
- `ship-pr` no longer reports "NOT merged" for a pull request that its own merge-on-green arm merged while
  it waited.
- The optional live issue dashboard is retired. If your `scripts/repo-config.ps1` defines
  `Get-IssueDashboardWorkerName`, you can delete it, because nothing reads it any more. If you ever deployed
  the worker, remove it with `npx wrangler delete <repo>-issue-dashboard`.
