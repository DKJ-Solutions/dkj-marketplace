# Release notes v6.6.0 🚀

**Date:** 2026-11-04\
**Type:** Minor\
**For whom:** consumers of this product

Shipping survives GitHub's bad minutes, merge-on-green stops making the last PR wait, and the brand book gains a width bar.

## What changed

Shipping a pull request now holds up when GitHub cuts an answer short or briefly locks a merge, and the
merge-on-green runner merges the last green PR within minutes. The brand book adds a width bar, a fifth paper
step and a two-word page name. The Toolbox settles on one full page width, and its hub stays up while Claude
Code still runs.

### Faster merge-on-green

For repos that placed the CI floor with `adopt-ci-floor`. The merge-on-green runner now waits out the settle
window, so the last armed pull request to go green is merged within about 11 minutes, not at the next
3-hourly run. On a private repo that costs at most about 11 billed Actions minutes, and only on a run the
settle window held back.

**Action:** re-run `adopt-ci-floor` to place the new runner. Until then your current one keeps working as
before.

### Shipping survives GitHub hiccups

No action needed. If GitHub cuts its reply short after creating your pull request, `open-pr` and `ship-pr`
no longer report a failed create. They find the PR and set its label, assignee and milestone. If GitHub
answers a merge with a server error or `Merge already in progress`, `ship-pr` waits about a minute for the
merge, then folds. If the merge still has not landed, it leaves the PR armed for the merge-on-green sweep,
and it no longer blames a merge queue you do not have.

### A width bar

For DKJ-Solutions apps on the brand book. `DKJTheme.widthBar(el)` puts full, fluid and phone as three small
icon buttons in a thin strip above your site header, so your users change the page width in one click. The
house style also gains a fifth paper token, `--bg-5`, one step past `--bg-4` in all twelve themes. No existing
colour moved.

### Two-word page names

For DKJ-Solutions apps on the brand book. A page's name, its `h1` and the matching breadcrumb crumb now hold
to two words; a hyphenated word counts as one. `h2` and `h3` keep their five-word cap. The hub warns on any
page whose `h1` or current crumb runs longer.

**Action:** when a page warns, move the subtitle out of its name and into the page itself, so "Subject - a
subtitle" becomes "Subject".

### One Toolbox width

No action needed. The Toolbox now always uses the full page width, because it is read in VS Code's Simple
Browser and never on a phone, so its Settings page no longer offers a width. Your product pages keep the
choice, through the width bar and their own Settings page. The airsquats banner now appears on Toolbox pages
only, and product pages open on their site header.

### Hub stays up

No action needed. On a machine where you switch between two accounts, the dev-preview watcher no longer stops
your Toolbox hub while the Claude Code that started it is still running. It stops the hub once no Claude Code
is left in that session.
