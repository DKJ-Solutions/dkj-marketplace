# Release notes v6.5.0 🚀

**Date:** 2026-11-03\
**Type:** Minor\
**For whom:** consumers of this product

Every release cut is timed by the Stopwatch, the hub gains a rules page and plugin contents, and the brand book checks type and weight.

## What changed

The brand book's gate now checks font sizes and weights, so a DKJ-Solutions repo may see new findings at its
next merge. Sessions stop publishing claude.ai Artifacts. Every release cut is timed on the Stopwatch, and
the toolbox gets a Rules page, a Performance page with sections, and a cleaner header.

### New font checks

For DKJ-Solutions repos running the house-style gate. A rule in your own stylesheet layer must now read its
font size from the type scale (`var(--text-*)`) and its font weight from one of the four house weights
(`var(--font-weight-light|regular|bold|black)`, 300/500/700/900). A typed `15px`, `0.88em`, `600` or `bold`,
including inside a `font` shorthand, is a finding. The CI workflow tracks `main`, so the findings arrive at
your next merge rather than at your next plugin update.

**Action:** replace each typed size or weight with the house token. There is no semibold, so a `600` becomes
bold or regular. A step of your own, such as `--text-hero: 48px`, stays allowed as a custom property. For a
genuine false positive, add an allowlist entry with its reason.

### No more Artifacts

No action needed. After this update, sessions no longer publish claude.ai Artifacts or Claude Docs, even where
the harness offers one unprompted. A result you need to judge becomes a Toolbox page, and a document becomes a
file in your repo. The Toolbox's Artifacts page is gone; an old `/artifacts` link lands on the home page.

### Live theme API refused

For Shopify store repos. A theme write aimed at the live theme through `shopify store execute` is now refused,
even with the live-push marker. Push merged work with `shopify theme push`, the command `live-preflight`
composes. No documented flow used the API route, so for most stores nothing changes.

### Every cut is timed

No action needed. Each release cut now appears as a `release cut` card on the hub's Stopwatch page without
anyone asking for it, so you can compare one cut with the next.

### Renamed folders keep history

No action needed. If you renamed a checkout's folder, its earlier Stopwatch cards and Logbook runs come back
on the hub the first time it runs after this update. Nothing is moved or deleted, and runs from a fork or
another repo never cross over.

### Rules and Performance pages

No action needed:

- **Rules** (`/claude/rules`) now lists one card per file in your `.claude/rules` folder, each opening on the
  file itself. Path-scoped rules are marked.
- **Performance** now has two sections, Clock (Stopwatch and Logbook) and Context (SessionStart), so the
  Stopwatch and Logbook are one click closer. An old `/clock` link moves to `/performance`.
- **The Logbook** shows the newest 20 runs, with older ones behind **Older runs**, and a run page opens
  without the delay that grew with every session.

### A cleaner header

No action needed. The settings gear is gone from the toolbox and product headers; choose your theme on the
Settings page. The header menu now stands at the right, and the breadcrumb trail lines up with the app name.

### Simpler pages by design

No action needed. Pages built in a DKJ-Solutions repo now follow a few more house rules: one table in the
brand book says which card and heading shape a page takes, Gwen keeps designs to one purpose without
explanatory chrome, and rendered text never uses an em dash.
