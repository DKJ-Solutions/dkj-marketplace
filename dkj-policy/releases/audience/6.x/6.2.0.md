# Release notes v6.2.0 🚀

**Date:** 2026-11-02\
**Type:** Minor\
**For whom:** consumers of this product

## What changed

### Taking the new brand book copy? Rename these tokens first

If your repo's own domain layer reads a brand book token, rename it when you take this release's
`house-style.css`. **There is no alias**: a use left behind loses its colour, corner or size, and the
house-style check names each one as a retired token.

| old | new |
|---|---|
| `--paper-1` … `--paper-4` | `--bg-1` … `--bg-4` |
| `--muted` | `--primary-muted` |
| `--cat-1` … `--cat-3` | `--graph-1` … `--graph-3` |
| `--muted-inverse` | `--bg-4` (on an inverted surface) |
| `--radius-xs`, `-sm`, `-md`, `-md-plus`, `-lg` | `--radius-1`, `-1-5`, `-2`, `-2-5`, `-3` |
| `--text-lg` | `--text-h3` |
| `--font-serif` | none: text falls back to the sans |

Every value is unchanged, so after the rename your pages look as they did. The full table is in the brand
book's README.

### …and these classes, because a leftover fails without an error

Eleven classes are gone. A page that still uses one does not break, it just loses the styling, so search
for them rather than waiting to notice:

- `.muted`, `.footer-note` and `.sub` → `.note`, the one class for quiet text.
- `.pos` / `.neg` → `.delta delta--up` / `.delta delta--down`.
- `.amount` → `.num`, with the icon inside it: `<span class="num">12,50<svg…></span>`.
- `.verdict` → `<p><strong>…</strong></p>`.
- `.eyebrow` and `.lead`: drop them (or set the eyebrow line as a `.note`).
- `.card__title`, `.menu-item__title`, `.group-heading` and `.msg`: drop the class. Headings take no class
  any more; their place styles them.

Also check spacing: **a `<p>` has no margin of its own any more**, so a run of plain paragraphs that relied
on the browser's default gap needs one from its container.

### Your pages will look different: heavier text, larger headings

No action needed, but expect it:

- Running text is a step heavier (500). `h1`, `h2` and `h3` are all bold (700), and `h3` takes the theme's
  `--primary`. Headings are larger: 36 / 22 / 16 px.
- Four weight tokens, `--font-weight-light`, `-regular`, `-bold` and `-black`. If your own layer sets a
  weight, use one of these instead of a number.
- Two new colour tokens per theme, `--primary-raised` and `--primary-hover`, for a shade a component needs.
- The settings toggle is a plain gear icon, and in a site header a full-height cell at its right edge.
- `--bg-2` stands a little further off the page, and on dark themes `--primary-muted` follows its own
  primary's hue.

### The skill is now called `dkj-brandbook`

The house style skill is renamed `dkj-solutions:dkj-brandbook`. **Act only if something of yours calls it
by its old name, `house-style`**: point it at the new one. Your vendored `house-style.css` and
`house-theme.js`, and your CI call to the house-style check, stay exactly as they are.

### SCSS repos: no more false `[redefine]` findings

If your styles are SCSS, the house-style check now reads nesting and interpolation (`.a-#{$n}`) the way
the brand book's rule means it: a house class nested inside a rule of your own is composition, not a
redefinition. You can drop any flattening or allowlist entry you added to get past it. No action needed
otherwise.

### Clearer plugin descriptions

Every plugin's description is rewritten for the person installing it: what it gives you, when to enable
it, and what it needs. You see it in `claude plugin details` and on your toolbox's Plugins page. No action
needed.
